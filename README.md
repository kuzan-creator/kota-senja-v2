Kota Senja v2 — an original 3D open-world crime game in a fictional Indonesian coastal city at dusk. You are Raka, a young mechanic, working ten story missions across Pantai Senja, Pasar Baru, Pelabuhan, Bukit Hijau, Kampung Nelayan and Terminal: on foot and by car, with traffic and pedestrians, car theft, a wanted system with police cars, foot police, roadblocks and a police helicopter, a weapon wheel with four weapons, garage upgrades, respect ranks, procedural radio, shops and safehouses, street races, and a crew member who fights beside you. Built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network — the game runs fully offline from its static files. Three.js 0.160.0 is vendored under `game/vendor/`.

## How to play

- **W A S D** move / drive · **Shift** run · **E** enter or steal a car, talk, shop
- **Mouse click** shoot · **1–4 / Q** weapon wheel · **C** call crew · **R** radio · **P / Esc** pause
- Earn money from missions and street races, spend it in the garage and shops, save at safehouses. Wanted level 1–5 brings more police: roadblocks at 3+, a helicopter with a searchlight at 4–5.
